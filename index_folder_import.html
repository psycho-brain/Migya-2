    管理者専用。管理者2名で共通の認証情報を使用します。

    アイテム管理

    数量は在庫数です。レアを有効にすると、抽選重みが通常アイテムより低くなります。数量0のアイテムは抽選されません。

    画像名称数量レア画像URL操作

    アイテムを追加・編集

    コードから複数アイテムを追加

    JSON配列で複数件を一度に登録できます。例：名前、数量、レア判定、画像URL、追加情報。

    画像フォルダーから自動でアイテム追加

    画像フォルダーを選ぶと、中の画像を1枚ずつアイテムとして自動登録します。ファイル名がアイテム名になり、登録後に「編集」から名前・数量・レア設定を変更できます。対応形式：PNG / JPG / GIF / WEBP / SVG。

    フォルダー未選択

    画像はこのブラウザー内に保存されます。別端末と共有する場合は、設定・アイテムをJSON出力して移行してください。
